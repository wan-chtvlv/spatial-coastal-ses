# spatial-coastal-ses
16.450.517-Socio-Ecological System Mapping with Python
Fall 2026 | Syllabus (directed study)
Prof. Lei Song and Wan Chantavilasvong

Objective of study or experience: 
The objective of this directed study is for the student to gain advanced python skills on dynamic spatial analysis. This directed study will be project-based focusing on modelling integrated socio-ecological systems dynamics with spatial analyses. The student has prior skills in spatial analysis and python programming as background for this advanced level integration. 
This class is also a part of the Geospatial Information Science Certificate program as an advanced topic for geospatial information science requirement.

Criteria for assessing student performance:
Grades will be based on the continued advancement of the project throughout the semester. The student will be submitting her project development 4 times throughout the semester:
1.	Submission 1 Project GitHub Repo (due September 4)
      o	Setting up a GitHub repository to share the work progress and submission
      o	Setting up access to Amerel computing (visit: https://oarc.rutgers.edu/resources/amarel/) 
2.	Submission 2 Project outline (due October 2): The outline document should include...
      o	Introduction
      o	Literature review
      o	Causal loop diagram (CDL) and stock and flow diagram (SFD) of the SES dynamic, which are based on a review of literature or projects. These will serve as the overall model framework.
      o	Provide a list of candidate datasets
3.	Submission 3 Project draft (due November 6): To show the progress of work, a draft of project document should include…
      o	Draft of the Methodology
      o	Revised CDL and SFD, if any
      o	Revised list of datasets used
      o	List of variables and equations used
      o	Preliminary results
4.	Submission 4 Final project (due December 11): The final project is submitted in 2 parts as follow…
      o	A 15-minute presentation that shows the framework, method, and result of the project
      o	A 10–20-page paper (including tables and figures) that has the following sections:
            	Introduction
            	Literature review
            	Methodology
            	Results
            	Discussions
